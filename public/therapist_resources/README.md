# PamWill Practitioner Verification Resources (`therapist_resources/`)

This directory stores verified identity documents, government clearance certificates, professional wellness diplomas, and direct payout mandates for all registered PamWill practitioners.

## Directory Structure:
- `aadhaar/`: Scanned Aadhaar cards (front & back) with masked 12-digit UIDAI validation.
- `police_clearance/`: State police character clearance certificates issued within the last 6 months.
- `certifications/`: Accredited diplomas (CIDESCO International, NASM, Ayurvedic Panchakarma, Deep Tissue).
- `banking/`: Cancelled cheques, bank statements, or verified UPI mandates for direct daily earnings transfers.

## Verification Protocol:
1. Every practitioner submitting through the PamWill 5-Step Onboarding has their credentials indexed here.
2. Platform Administrators review these records in the Admin Console Verification Queue before granting **Approved** status.
