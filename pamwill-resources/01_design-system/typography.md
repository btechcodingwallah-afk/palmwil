# PamWill Typography System — "Minimalist Luxury"

## Typefaces
- **Display / Headings**: *Playfair Display* / *Fraunces* (refining high-contrast editorial serif).
- **Body / Interface**: *Inter* / *General Sans* (humanist, legible, clean).

## Hierarchy & Scale
- **H1**: 36px / Line Height 1.2 / Letter Spacing -0.5px (Playfair Display)
- **H2**: 28px / Line Height 1.3 / Letter Spacing -0.3px (Playfair Display)
- **H3**: 22px / Line Height 1.35 / Letter Spacing 0px (Playfair Display)
- **Eyebrow / Category Tag**: 11-12px / Uppercase / Letter Spacing +2.5% to +4% (Inter Bold)
- **Body Large**: 17px / Line Height 1.5 (Inter Regular)
- **Body Standard**: 15px / Line Height 1.5 (Inter Regular)
- **Caption / Meta**: 13px / Line Height 1.4 (Inter Regular/Medium)
- **Button / Action Label**: 15px / Semi-Bold / Letter Spacing +0.5px (Inter SemiBold)

## Tone of Voice
Calm, confident, understated. Breathing room over density. Restraint over exclamation marks.
