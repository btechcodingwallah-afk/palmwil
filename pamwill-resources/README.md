# PamWill — Master AI Build Prompt
### On-Demand Massage Therapy App (React Native · 3 Interfaces)

This repository contains the full production blueprint and implementation for PamWill — a luxury on-demand massage therapy platform tailored for the Indian wellness marketplace.

## Structure
- `01_design-system/`: Design system tokens (colors, typography, spacing, components).
- `02_client-app-prompt.md`: Customer mobile application specs and flows.
- `03_therapist-app-prompt.md`: Provider mobile application specs and verification flows.
- `04_admin-console-prompt.md`: Operations and executive console specs.
- `05_data-models/`: Schema definitions and service catalog seed.
- `07_business-logic.md`: Commission structure, booking state machine, and safety logic.
